# Project Snapshot Guidelines

Add all project screenshots in this folder.

Recommended naming:
- 01-home-dashboard.png
- 02-wallet-analysis-result.png
- 03-risk-breakdown.png
- 04-transaction-graph.png
- 05-ai-insights.png
- 06-report-preview.png

Tips:
- Use PNG format for better readability in reports.
- Keep resolution around 1366x768 or higher.
- Capture both normal and edge-case analysis examples.
